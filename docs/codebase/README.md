# Codebase map

Short documents about what this code already is, generated by the Loop Harness so the team and the AI can reuse them.
They are a guide, NOT the source of truth: when a document and the code disagree, the code wins.
Read one only when the task needs it. If a change really alters one of them, update it in the same change.

- [ARCHITECTURE.md](ARCHITECTURE.md): layers, patterns and how data flows
- [CONCERNS.md](CONCERNS.md): tech debt, risks and fragile areas
- [CONVENTIONS.md](CONVENTIONS.md): naming, code style and error handling in use
- [INTEGRATIONS.md](INTEGRATIONS.md): external APIs, databases, queues and authentication
- [STACK.md](STACK.md): languages, frameworks, versions and main dependencies
- [STRUCTURE.md](STRUCTURE.md): folder layout and where each kind of code lives
- [TESTING.md](TESTING.md): how tests are written and run
