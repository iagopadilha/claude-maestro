# Tech Stack

**Analyzed:** 2026-10-19

## What the repo is
Two parts in one repo: a **Claude Code plugin** (`plugin/`, "loop-engineering-harness": skills, agents, hook, shared scripts) and a **local control panel app** (`app/`) that runs and shows the `/orchestrator` loop. See `README.md` and `app/docs/ARCHITECTURE.md`.

## Core
- Language / runtime (app back end, engine, plugin scripts, `install.py`): Python 3.10+, **standard library only**. No manifest (requirements.txt, pyproject): not found.
- Package manager: none.

## Frontend (`app/frontend/`)
- UI: Preact + htm, **vendored** in `app/frontend/vendor/`, resolved by an import map in `index.html`. Single import point: `src/util/preact.js`.
- Native ES modules served by the back end. No npm, no bundler, no build step.
- Styling: plain CSS files in `app/frontend/styles/`.
- State: Preact hooks plus polling helpers in `src/api/api_client.js`; no state library.

## Backend (`app/backend/harness_backend/`)
- API: REST/JSON over a custom router and HTTP server on the standard library (`api/router.py`, `api/http_server.py`); local only (127.0.0.1, token on mutating calls). Routes: `app/docs/API.md`.
- Persistence: files only (no database). Loop state lives in `.specs/` of the managed project; app data in `~/.loop-harness/` (`config.json`, `.env`).
- Auth: no user auth; local token plus Host check.

## Testing
- `unittest` (stdlib), no network, fake `claude`. Run: `python -m unittest discover -s backend/tests -t backend` from `app/`.

## External tools (called as processes)
- `claude` CLI (the model runtime; uses the user's subscription, no API token), `git`, optional `gh` (PR on deliver). See `infrastructure/claude_client.py`, `git_client.py`, `process_runner.py`.
- `claude-dev-toolkit` (plugin, separate repo; required): the generic dev skills and `shared/` scripts the agents run. `harness.py paths` prints where it is, `harness.py doctor` FAILs without it.
- Notification channels (email and others): `engine/notify.py`, `engine/email_senders.py`, configured via `app/.env.example`.

## Plugin (`plugin/`)
- Markdown skills and agents (`SKILL.md`, `references/`), a PreToolUse guard hook in Python (`plugin/skills/orchestrator/hooks/guard.py`), a template and `envload.py` in `plugin/shared/` (the dev skills and their shared scripts are not here: they come from the required companion plugin claude-dev-toolkit, found by `config/skill_locator.find_toolkit_root`). Manifest: `plugin/.claude-plugin/plugin.json`; marketplace: `.claude-plugin/marketplace.json`.

## Development tools
- CLI entry: `app/harness.py` (serve, loop, check, state, deliver, doctor, install...). Setup: `python install.py`.
- Linter / formatter / CI config: not found.
