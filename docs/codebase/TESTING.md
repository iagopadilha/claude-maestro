# Testing

## How to run
- Back end and engine (Python 3.10+, standard library only, `unittest`):
  `python -m unittest discover -s backend/tests -t backend` from `app/` (see `app/README.md`).
- Plugin guard hook: tests live next to the hook, `plugin/skills/orchestrator/hooks/test_guard.py` and `test_guard_cookbook.py`. How to run them: unclear (no runner documented).
- No CI config found (no `.github/workflows`).

## Kinds of tests that exist
| Kind | Where | Notes |
|---|---|---|
| API / service tests | `app/backend/tests/api/test_*.py` | Exercise the layered HTTP API (hub, projects, roadmap, commands, read endpoints). Shared builders in `support_*.py`. |
| Engine tests | `app/backend/tests/engine/test_*.py` | Loop, close loop, delivery, credentials, multi-repo, notifications. Helpers: `engine_env.py`, `multi_repo_world.py`. |
| CLI contract tests | `app/backend/tests/engine/test_cli_contract.py` | Parse real-shaped `claude` CLI output from `engine/fixtures/cli/` (success, errors, garbage, stream-json). |
| Infra tests | `app/backend/tests/infra/test_*.py` | Git client, claude client, process runner, install script, `harness.py` CLI. |
| Demo story | `app/backend/tests/demo/test_demo_story.py` | Covers the demo mode. |
| Guard hook tests | `plugin/skills/orchestrator/hooks/test_guard*.py` | Block/allow rules of the guard. |

## Doubles
- `engine/fake_claude.py` stands in for the `claude` CLI; `engine/fake_app.py` for the app. Tests do not call the real model. Scenario keys (JSON) include `argv_log` (a file that gets one JSON line with the whole argv of every call, used to check `--model`) and `decision_lines` (`{"<turn>": ["- [slug] turn=.. level=.. doubt | chose: .. | revert: .."]}`, lines that turn appends to `VALIDATE.md`).

## Conventions
- New tests go in the folder of the layer they cover (`api`, `engine`, `infra`), named `test_<topic>.py`, with shared setup in a `support_*`/`*_env` helper rather than copied.
- Test pieces named `test_environment_*` in `harness_backend` are the product's "test environment" feature, not tests.
